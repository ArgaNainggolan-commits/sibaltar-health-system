# Layanan Kesehatan SIBALTAR

Sistem direktori informasi layanan kesehatan berbasis web yang mencakup wilayah Siantar, Balige, dan Tarutung. Proyek ini bertujuan untuk memusatkan akses informasi medis bagi masyarakat umum secara digital.

## 🚀 Fitur Utama
* **Regional Filtering:** Mempermudah pengguna mencari fasilitas kesehatan, poliklinik, dan tenaga medis spesifik berdasarkan kota (Siantar, Balige, Tarutung).
* **Comprehensive Directory:** Menampilkan profil rumah sakit, jam operasional, serta daftar dokter secara terstruktur.
* **CRUD Management:** Manajemen data backend untuk memperbarui informasi fasilitas kesehatan secara berkala.

## 🛠️ Stack Teknologi
* **Web Stack:** PHP, HTML, CSS, JavaScript, MySQL.
* **Arsitektur Database:** Relational Database Management System (RDBMS) dengan operasi CRUD penuh.
